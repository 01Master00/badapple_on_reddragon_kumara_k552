# BadApple!!_on_reddragon_kumara_k552
A 9*5 pixel display of Bad Apple!! on the Reddragon Kumara K255 keyboard

note that it can run on any keyboard that has 
1. leds that can be modified seperately
2. is supported by OpenRGB
3. 
IMPORTANT: if the keymapping is off by atleast 1 led this will not look like Bad Apple!!

# Parts of the project
this project is built from 2 main components:
- Bad Apple!! converted into 9*5 pixels stored in binary (1 line = 1 frame)
- the python file itself that runs it

# How to run it
1. clone the project (git clone https://github.com/01Master00/badapple_on_reddragon_kumara_k552)
2. download OpenRGB
3. start the SDK Server (at the SDK Server tab) and don't change anything
4. run BadApple.py (python "path/BadApple.py")
5. Enjoy Bad Apple!!
